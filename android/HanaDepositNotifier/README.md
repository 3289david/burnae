# Burnae 입금알림 (HanaDepositNotifier)

하나은행 Open API는 실시간 웹훅이 없어서(`src/lib/hanabank.ts` 참고) 서버는 10분마다 거래내역을
폴링해서만 입금을 확인했다. 이 앱은 휴대폰에 뜨는 **하나은행 앱 알림을 그대로 읽어서** Burnae
서버(`/api/webhooks/hanabank-notification`)로 즉시 전달해, 몇 초 안에 결제를 체결시킨다.

서버 쪽 매칭 로직은 크론과 동일하게 **입금자명 + 금액이 둘 다 일치**해야만 체결된다(계좌를
다른 용도로도 쓰기 때문).

## 빌드하기

이 서버 환경에는 Android SDK가 없어서 직접 컴파일/테스트하지 못했다. Android Studio에서
`android/HanaDepositNotifier` 폴더를 "Open" 하면 Gradle Sync가 자동으로 wrapper까지
내려받는다(이 리포에는 `gradle-wrapper.jar` 바이너리를 커밋하지 않았음 — 텍스트 파일만 있음).
Studio 없이 `./gradlew`로 직접 빌드하려면 먼저 `gradle wrapper`를 한 번 실행해 jar를 만들어야 한다.

- compileSdk/targetSdk 34, minSdk 26, Kotlin 1.9.24, AGP 8.5.2
- 빌드 후 실제 기기에 설치(에뮬레이터는 알림 접근 권한 테스트가 번거로워 실기기 추천)

## 설정 순서

1. 앱 설치 후 실행 → "알림 접근 권한 설정 열기" 버튼으로 시스템 설정에서 이 앱의 알림 접근을 켠다.
2. **서버 주소**: `https://<배포한 도메인>/api/webhooks/hanabank-notification`
3. **시크릿 키**: 서버 `.env`의 `HANABANK_NOTIFY_SECRET` 값과 똑같이 입력 (운영 서버에는 이미
   발급해서 심어뒀음 — 관리자에게 받아서 입력)
4. **하나은행 앱 패키지명**: 처음엔 비워두고 저장. 하나은행 앱 패키지명을 확실히 몰라서
   하드코딩하지 않았다 — 비워두면 "로그만 남기는 모드"로 동작해 시스템에 뜨는 알림을 전부
   패키지명과 함께 기록만 한다(전송은 안 함). 실제 입금이 한 번 와서 하나은행 앱 알림이 뜨면,
   앱을 다시 열어 "최근 알림 로그"에서 그 알림의 패키지명을 확인해 이 필드에 입력하고 저장.
   그 다음부터 그 패키지의 알림만 파싱해서 전송한다.
5. **금액/입금자명 정규식**: 기본값은 "입금 100,000원 홍길동" 같은 흔한 형태를 가정한 추정치다.
   실제 알림 문구가 다르면(은행 앱 업데이트로 바뀔 수도 있음) 로그에서 원문을 보고 정규식만
   고치면 된다 — 앱을 다시 빌드할 필요 없음.

## 보안 참고

- 시크릿 키는 길고 무작위한 값을 쓰고, 이 앱의 설정값과 서버 `.env` 두 곳에만 둔다.
- 통신은 HTTPS로만(서버 주소를 http로 넣지 말 것).
- 알림 접근 권한은 기기의 모든 알림을 읽을 수 있는 민감한 권한이다. 이 앱은 설정된 패키지명과
  일치하는 알림만 서버로 전송하고, 나머지는 로그(기기 로컬 저장, 최근 20개)에만 남긴다 — 그래도
  이 권한을 신뢰할 수 있는 기기에만 설치해야 한다.
